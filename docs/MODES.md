# Experiment modes

| Mode | Intent |
|------|--------|
| `auto` | Choose the best mode from tonight's signals/convergences |
| `missing-primitive` | Invent infrastructure primitives agents still lack |
| `technology-collision` | Products that only exist when capabilities collide |
| `resurrection` | Revive archived ideas when the world changed |

Mode prompts live under `backend/app/prompts/modes/`.
Mode selection and implementations live under `backend/app/modes/`.
